# Сейчас в файле нет ни одной строки с вопросом — в игре
# работает ПЕРВИЧНАЯ ЗАГЛУШКА. Заполните файл своими вопросами
# (6-8 штук), и они автоматически подхватятся при сборке.
#
# ФОРМАТ ОДНОЙ СТРОКИ:
#
#   № "Вопрос" "Правильный ответ" "неправильный" "неправильный" "неправильный"
#
# Пример (можно раскомментировать и проверить):
#
#   1 "Какой номер у скорого поезда?" "№037" "№777" "№13" "№9 и 3/4"
#
# Правила:
#   - каждый вопрос — на отдельной строке;
#   - вопрос и все четыре ответа — в двойных кавычках;
#   - № в начале строки — по желанию, можно без него;
#   - строки, начинающиеся с #, — комментарии (игнорируются);
#   - пустые строки игнорируются;
#   - в строке должно быть минимум 5 блоков в кавычках,
#     иначе строка пропускается (игра не сломается).
#
# Поведение в игре:
#   - при каждой смерти выбирается СЛУЧАЙНЫЙ вопрос;
#   - порядок вариантов ПЕРЕМЕШИВАЕТСЯ каждый раз,
#     правильный ответ никогда не стоит на одном и том же месте.

# ============================================================
#
# Формат одной строки:
#
#   № "Вопрос" "Правильный ответ" "неправильный ответ" "неправильный ответ" "неправильный ответ"
#
# Правила:
#   - каждый вопрос — на отдельной строке;
#   - вопрос и все четыре ответа пишутся в двойных кавычках;
#   - № в начале строки — по желанию, можно писать без него;
#   - строки, начинающиеся с #, игнорируются (комментарии);
#   - пустые строки игнорируются;
#   - вопросов может быть сколько угодно (нужно минимум 5 цитат в строке).
#
# Поведение в игре:
#   - при каждой смерти выбирается СЛУЧАЙНЫЙ вопрос;
#   - порядок вариантов ответа ПЕРЕМЕШИВАЕТСЯ каждый раз,
#     правильный никогда не стоит на одном и том же месте.
#
# Примеры ниже — замените их на свои 6-8 вопросов:
# ------------------------------------------------------------

1 "Какого цвета бойцовка у Володи?" "Тёмно-коричневая" "Ярко-розовая" "В горошек" "Из фольги"
2 "Что написано на табличке в тамбуре?" "Таня ждёт в следующем вагоне" "Осторожно, злая проводница" "Вагон-ресторан закрыт навсегда" "Компостер не работает"
3 "Какой номер у скорого поезда?" "№037" "№777" "№13" "№9 и 3/4"
4 "Что Володя собирает по пути?" "Фотографии для альбома" "Грибы" "Пустые бутылки" "Чужие тапки"
5 "Что свисает с верхней полки?" "Ноги в чёрных носках" "Люстра" "Продавец шаурмы" "Дед Мороз"
6 "Куда едет поезд?" "Новосибирск — Москва" "Москва — Владивосток" "В никуда" "В отпуск"
7 "Кто ждёт Володю на конечной?" "Таня" "Полиция" "Бывшая" "Никто, все спят"
